# Golf_Buddy

The Golf Buddy is a universal digital golf scorecard that can be used on any course and can be set for either 9 or 18 holes games.

Inspiration for this project came from often loosing track of strokes and forgetting to write them down on the course provided scorecards.

The goal was to develop a product that was:  - Simple and quick to understand/use
                                             - Comfortably fit in a pants pocket
                                             - Lasts a single round of golf on a single charge
                                             - Provided quick analytics of game performance
