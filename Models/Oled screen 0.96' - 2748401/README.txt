Oled screen 0.96' by frogmax on Thingiverse: https://www.thingiverse.com/thing:2748401

Summary:
This is a 3d model of a 0.96', OLED screen with I2C communication. I needed the 3d model of the part to precisely design its enclosure, so I made it in openScad.There is a lot of variation between the different manufacturer, so this model may not be the exact copy of what you bought, but the scad file should be fairly simple to adapt (the scad file is not well commented and very messy, but is only 60 lines long).
